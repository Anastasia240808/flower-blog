# Блог о цветах

Учебный блог на PHP + Smarty + MySQL. Статьи разделены по категориям, есть сортировка и пагинация, адаптивная вёрстка (SCSS).

## Что нужно

- Docker и Docker Compose
- Node.js и npm (только если нужно пересобирать стили)

## Запуск

Папка `vendor/` (библиотека Smarty) уже лежит в репозитории, ставить зависимости PHP отдельно не нужно.

1. Запустить сайт и базу данных:

```bash
   docker compose up -d --build
```

2. Создать таблицы и заполнить их тестовыми данными (подождите несколько секунд после запуска, пока стартует MySQL):

```bash
   docker compose exec web php src/seed.php
```

3. Открыть сайт: http://localhost:8080

Остановить проект: `docker compose down`.

## Стили

Исходники SCSS лежат в `public/assets/scss/`, скомпилированный файл в `public/assets/css/style.css`. Пересобрать CSS после правок:

```bash
npm install
npm run sass
```

Автопересборка при изменениях: `npm run sass:watch`.

## Структура проекта

```
public/              
  index.php          точка входа и маршрутизатор
  assets/            стили (scss, css) и картинки
src/
  Controllers/       контроллеры страниц (главная, категория, статья)
  Models/            запросы к базе данных
  templates/         шаблоны Smarty (layouts, pages, partials)
  config/            подключение к базе
  seed.php           сидер: создаёт таблицы и тестовые данные
database/            схема БД и тестовые данные
apache/              конфигурация Apache
```

## Страницы

- `/` — главная: категории и по 3 последние статьи в каждой
- `/?route=category&id=1` — статьи категории, сортировка по дате и просмотрам, пагинация
- `/?route=article&id=1` — статья с похожими статьями

## Использование ИИ

При работе над проектом я использовала ИИ-ассистента Claude. Где и для чего:

- **Адаптивная вёрстка.** ИИ предложил правки в SCSS: шапка и выпадающее меню категорий на телефонах, переключатель сортировки, сетка карточек.
- **Публикация на GitHub.** ИИ помог настроить Git, подготовить `.gitignore` и отправить проект в репозиторий.
- **Smarty..** ИИ объяснил, как работают шаблоны Smarty.
